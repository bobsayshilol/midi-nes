# MIDI NES

This library provides MIDI output for C/C++ NES emulators by attempting to match how basicNES 2000 produced its output.

The [header](midines.h) should be simple enough to understand, but see the [example](example.cpp) for detailed use of it.

Almost all of the code is a translation of olafnes 1.1c (which is a continuation of basicNES 2000) to C++, so nothing here is original.
